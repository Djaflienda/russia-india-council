# Российско-Индийский Деловой Совет

**Сайт:** https://djaflienda.github.io/russia-india-council/

**Репозиторий:** https://github.com/Djaflienda/russia-india-council

Адаптивный визуальный прототип по Figma: `ZMHQi5SYy6PmRHwlfNq7tx`, экран **Desktop - 17**, узел **2:918**.

Статический сайт без сборки и внешних зависимостей. Изображения, SVG и шрифты хранятся в `assets/`. Для просмотра запустите `python3 -m http.server 4173` в этой папке и откройте http://localhost:4173.

Работают мобильное меню, переходы между разделами, русский и английский языки, окна новостей и календаря, проверка полей формы. Форма демонстрационная: ничего не отправляет и не сохраняет. Полные статьи, юридические документы, контакты и социальные ссылки отсутствуют в исходном макете, соответствующие элементы открывают честные демонстрационные пояснения.

Мобильной версии в Figma нет; адаптивная композиция разработана для ширины от 320 px. Тексты, даты и статистика взяты из макета и не являются проверенными редакционными данными.

## GitHub Pages

Публикация настроена из ветки **main**, папки **/ (root)**. После загрузки изменений GitHub Pages автоматически обновляет сайт.

Пути относительные, поэтому сайт поддерживает как корневой домен GitHub Pages, так и публикацию в подпапке репозитория.

## Обновления

Плашки под баннером анимируются однократно при появлении на экране (1,6 с, с задержкой 80 мс). При включённом уменьшении движения сразу показываются итоговые значения. Статистика предоставлена заказчиком. Блок Германа Грефа перенесён на `about.html`; там же подготовлен раздел «Правление Совета».
